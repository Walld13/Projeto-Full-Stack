Pseudo classe e Pseudo elementos 
    Pseudo-classe e pseudo-elemento são termos importantes no CSS que referem-se a seletores especiais que 
    permitem aplicar estilos com base em estados ou partes específicas de um elemento.

Pseudo-classe: São palavras-chave adicionadas a seletores que especificam um estado especial do elemento 
selecionado, como :hover, :visited, :focus, entre outros. Exemplos incluem color: blue; para alterar a cor 
de um elemento quando o mouse passa sobre ele. 

Pseudo-elemento: São representados por :: e estilizam partes específicas de um elemento, como a primeira 
letra de um parágrafo. Exemplos incluem ::first-letter para aplicar um estilo à primeira letra de um elemento de lista. 
Ambos os conceitos são fundamentais para criar efeitos visuais dinâmicos e interativos em páginas web, 
permitindo uma maior personalização e interatividade

Conceitos importantes para posicionamentos

Fluxo normal (position: static)
    - Cada elemento de nível de bloco aparece em uma nova linha, fazendo com que cada item apareça
    um abaixo do outro, mesmo que você defina uma largura e tenha espaço para ficar um ao lado do outro, 
    eles não ficarão, pois esse é o comportamento padrão (a menos que voce defina pra que seja feito 
    diferente)

Posicionamento relativo (position: relative) -  Movimenta sempre da posição original para outra como se fosse empurando de: EX Left: sai da esquerda para direita 
    - Move um elemento da posição que ele estaria no fluxo normal, deslocando para a parte superior, inferior
    esquerda ou direita de onde ele seria posicionado. Isso não afeta a posição dos outros elementos, pois eles 
    vão se comportar como se o elemento não tivesse sua posição mudada (parágrafo é deslocado para baixo e para 
    a direita de onde estaria o fluxo normal)

Posicionamento Absoluto (position: absolute) - Movimenta sempre da posição orginal para outra direção EX: se colocar top: ele vai direto para a posição superior 
    - Posiciona o elemento em relação a seu elemento contêiner (que tem a posição definida), o elemento
    é removido do fluxo normal, o que significa que ele não afeta a posição dos elementos próximos a ele
    Elementos posicionados de forma absoluta, movem -se a medida que o usuário rola a página pra cima ou para 
    baixo. (O título é posicionado na parte superior direita, e os parágrafos começam no topo da tela, como se 
    o título não existisse lá)

Quando acionado o position absolute, se não for relcionado com o position relative ele não vai se importar com a caixa.

Posicionamento fixo (position: fixed)
    - Essa é uma forma de posicionamento absoluto que posiciona um elemento em relação a janela do navegador,
    em vez de usar o elemento contêiner. Elementos com posicionamento fixo, não afetam a posição dos elementos 
    próximos e não se movem quando o usuário rola para cima ou para baixo da página (o título é posicionado 
    centralizado na página, não acompanhando a rolagem da tela, ficando fixo)

ELEMENTOS FLUTUANTES 
    - Fazer um elemento flutuar, permite remover esse elemento do fluxo normal e posicioná-lo mais a direita 
    ou esquerda de uma caixa contêiner

OBS: Se um elemento de nível de bloco estiver dentro de outro elemento de nível de bloco, essa caixa é conhecida como 
elemento contêiner ou pai.

É normal agrupar vários elementos, dentro de um elemento <div>(ou outro nível de bloco) esse elemento <div> que 
contém esses elementos é chamado de elemento contêiner ou pai.
---------------------------------------------------------------------------------------------------------------------------

Elementos flutuantes (float: right/ left)
    -Faz o elemento flutuar, permite remover esse elemento do fluxo normal e posicioná-lo mais a direita ou à esquerda
    de uma caixa contêiner (quando for definir os elementos flutuantes, definir também a altura e a largura dos tais)

EX: Uma div com logo do lado esquerdo e um menu do lado direito -  o menu é removido do fluxo normal e passa a flutuar 
a direita, ficando mais a direita dentro do contêiner ou elemento pai.
EX: Uma div com imagem a esquerda, paragrafo no meio, paragravo a baixo e um quadro vazio a esquerda - já aqui imagem flutuou
a esquerda, permitindo que os parágrafos de textos, flutuam ao seu redor 

 - Onde iremos utilizar elementos flutuantes?
    
    Criação de layouts dos sites = Muitos layouts posicionam caixas lado a lado e voce pode atingi esse objetivo, utilizando elementos flutuantes

 - Existem outras maneiras? 

    Flexbox e Grid - Normalmente utilizamos o grid para criar a estrutura do nosso site ou sistema e o flexbox para organizar os conteúdos e criar 
    os componentes 

---------------------------------------------------------------------------------------------------------------------------

CLEAR - Comando que "anula" o fluxo flutuante, o conteudo para de ficar flutuando em volta dos outros conteudos
(não fica em volta das imagens)

Pode ser usado para lados left e right ou até both que seria ambos os lados
